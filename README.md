# 🍽️ Restaurant Data Analyzer

A JavaScript project that analyzes restaurant data using modern ES6 features and array methods. This project demonstrates data manipulation and filtering techniques in JavaScript.

## 🚀 Features

- Search restaurant data
- Filter restaurants
- Sort restaurant records
- Calculate statistics
- Clean and reusable JavaScript code
- ES6 syntax implementation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ES6 Concepts Used

- Arrow Functions
- Destructuring
- Spread Operator
- Template Literals
- Map()
- Filter()
- Reduce()
- Find()
- Some()
- Every()
